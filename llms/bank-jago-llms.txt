# Bank Jago

> PT Bank Jago Tbk is a technology-based digital bank in Indonesia, delivered life-centric through the Jago mobile application and embedded into partner ecosystems (Gojek/GoPay, Bibit, Stockbit). Its payment API surface is exposed through Indonesia's national SNAP (Standar Nasional Open API Pembayaran) programme rather than a self-hosted developer portal. This profile is maintained by the API Evangelist network from public sources.
